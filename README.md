# 🎬 Interactive Scroll Animation

One of the main visual features of this portfolio is the **scroll-controlled image-frame animation**.

Instead of directly playing a video, the animation is created using individual image frames.

As the user scrolls through the page, the corresponding frames are displayed to create a smooth cinematic animation.
